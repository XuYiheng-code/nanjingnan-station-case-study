# 南站协同官｜工程启动包

这套材料把《南站协同官-智能体完整设计与落地蓝图》转成可开发、可测试、可演示的工程底稿。目标是完成比赛展示版：它围绕一个模拟的跨域枢纽事件，整理证据、提示权责边界、起草协同议题卡，并记录人工确认。它不接入真实业务系统，也不自动派单、执法或共享数据。

## 工程边界

- 演示环境只读取本目录内经审阅的脱敏材料和模拟情景，不读取原始访谈、车牌、旅客轨迹或真实工单。
- 每张协同议题卡必须带 `evidence_refs`、`knowledge_version` 和 `human_gate=true`；被引用的证据卡再提供对应的 `source_id`。任一项缺失即不能显示为“可确认”。
- 权责判断由 `authority-rules.json` 之类的结构化规则给出。大模型可以解释规则，不能改写规则的结论。
- 对外页面固定展示“案例教学与模拟推演”。不要使用任何暗示南京南站、交控万物或政府部门已部署、已授权的表述。

## 推荐实现顺序

1. 建立 `source-registry → evidence cards → authority rules` 三类数据。
2. 按 Schema 写出 SC-01，并完成无模型模式下的卡片生成与人工确认日志。
3. 接入可溯源检索和受限的大模型起草；无模型或校验失败时退回模板卡。
4. 最后做角色视图、讲解脚本、回归集和离线演示封装。

这份启动包只定义基线。原始材料的事实核验、脱敏和使用许可仍由研究团队负责。
