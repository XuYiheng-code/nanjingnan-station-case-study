# 可运行源码放置规则

这个目录只放后续还会继续编码、调试或复用的项目。每个项目独立成文件夹，不把多个项目混在同一套 `src/` 里。

## 新项目怎么放

新建项目时用这个结构：

```text
项目名/
├── README.md          # 项目用途、运行方式、数据边界
├── src/               # 可编辑源码
├── public/            # 静态资源或演示数据
├── docs/              # 方案、事实清单、接口说明
├── qa/                # 截图、验收脚本、测试记录
├── index.html         # 能直接打开时放这里
└── package.json       # 需要构建时再放
```

不是每个项目都必须有这些目录。小型 HTML 页面可以只有 `index.html`、`styles.css` 和 `script.js`；但只要项目会继续开发，就要有自己的 `README.md`。

## 不放这里的东西

- 终版视频、封面、字幕：放 `02-终版案例视频/`
- 一次性 HTML 成品或汇报页：放 `04-网页成品与展示材料/`
- Logo、海报、设计系统：放 `05-设计与视觉资产/`
- 论文稿、访谈原始材料、未脱敏数据：继续留在案例研究主目录对应资料区，不进入作品展示包

## GitHub 约束

本目录可以跟随合集一起上传到 GitHub。依赖包和构建缓存不要上传；根目录 `.gitignore` 已排除 `node_modules`、缓存和 Remotion 渲染输出。
