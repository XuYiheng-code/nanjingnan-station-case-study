# 事实与数据清单

更新时间：2026-09-06

## 使用规则

- A 级：政府、铁路或运营机构公开资料，可直接用于背景和校准。
- B 级：案例正文、访谈或调研对象材料，可用于案例叙述，界面需标注“案例材料”或“访谈”。
- C 级：为了演示而生成的参数，只能标为“教学推演”。
- 待核：来源或统计口径不足，暂不进入默认界面。

## 暂不直接使用的数字

| 原说法 | 问题 | 处理 |
|---|---|---|
| “铁路日发送量超过 30 万人次” | 可作为某些高峰日量级，但现有脚注没有给出南京南站单站、单日的直接证据；与 2024 年全年日均 17.4 万人次不是同一口径 | 默认界面改用 17.4 万日均。找到原始统计后再加入峰值情景 |
| “日车流量可达 8 万辆次” | 当前项目脚注不能直接支撑统计范围、日期和车辆定义 | 暂不进入界面 |
| “十余个条块部门” | 法规列举的部门较多，但不同材料对“部门、单位、运营主体”的计数方式不同 | 展示主体名称，不显示精确总数 |
| “地下 8 个停车场” | 案例叙述与 2024 年官方 P1—P7 地下停车场口径不一致，2026 年新增 P8 又是地面停车场 | 模型按时间拆分为“P1—P7 地下 + P8 地面”，不把不同时点合并成一个口径 |

## 推演参数

`public/data/scenarios.json` 中的速度、拥堵阈值、事件持续时间和粒子密度都属于 C 级参数。它们用于比较不同组织响应方式，不代表南京南站真实调度系统。
