# 视觉与交互规范

## 视觉概念

“轨迹秩序”是这套沙盘的视觉线索。建筑使用低饱和灰和纸白，人的移动以短轨迹呈现，组织介入才出现信号色。画面先让人看清站区，再让人看见问题怎样移动。

## 颜色

| 用途 | 色值 | 说明 |
|---|---|---|
| 墨黑 | `#11100E` | 顶栏、底栏和主要背景 |
| 深灰蓝 | `#172026` | 三维场景背景 |
| 纸白 | `#F3EFE6` | 建筑、铁路客流和主要文字 |
| 信号橙 | `#F28C45` | 告警、道路接驳、权限交接和待响应 |
| 冷蓝 | `#8FD7FF` | 地铁换乘与信息流 |
| 稳态绿 | `#8FBD8B` | 正常运行状态 |

颜色不能单独承担含义。状态必须同时出现文字、线型或图形变化。

## 字体与数字

- 中文标题使用 `Songti SC`，延续案例网站的纪实感。
- 界面正文使用 `PingFang SC`，并配置常见中文系统字体作为替代。
- 时间、倍率和数据标签使用 `SFMono-Regular` 或 `Menlo`。
- 正文在移动端不小于 12 px；关键操作不小于 44×44 px。

## 镜头

首版保留四个预设视角：

1. 总览：南偏东高位视角，解释站房与接驳区关系。
2. 站台剖切：隐藏站房上层，查看 15 台 28 线和换乘路径。
3. 地铁换乘：下降相机并聚焦两组地铁站台。
4. 停车边界：转向东西接驳区，突出场内外权限交接。

旋转和缩放使用阻尼，停止操作后不继续自动漂移。课堂自动讲解模式可使用缓慢推近，但不能取代用户控制。

## 动效

- 客流持续移动；事件节点只在状态变化时闪烁一次。
- 一般状态切换控制在 180–260 ms。
- 告警不用高频闪烁，避免干扰和可访问性问题。
- 用户暂停后，客流、镜头和时间轴全部停止。
- 开启 `prefers-reduced-motion` 时，默认暂停粒子，只显示密度带和方向箭头。

## 响应式

桌面端使用左控制、中央三维、右信息的三栏结构。宽度低于 820 px 后改为单列，先显示三维，再显示控制和职责。移动端不隐藏来源说明，也不允许横向滚动。
