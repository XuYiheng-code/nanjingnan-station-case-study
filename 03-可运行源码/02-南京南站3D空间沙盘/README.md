# 南京南站运行沙盘

这是基于案例文本与公开资料复原的南京南站三维治理运行沙盘。它用于呈现站场空间、客流、事件演进和跨部门决策，不是工程 BIM，也不接入实时运营数据。

## 当前状态

- 以南京南站大屋盖、15 台 28 线、南北落客平台与广场、东西接驳区、换乘层和地铁层为识别骨架。
- 补入南北高架落客坡道、客运南站、公交枢纽、出租车/网约车候车区、地铁入口和周边建筑体量。
- 新增“CAD 底图”俯视校核模式；底图与三维模型共用 `src/stationCad.ts` 中的坐标。
- 加入铁路、地铁、广场、停车接驳客流与车辆流动，并可按空间层级查看。
- 收录站区总览、2024 年 5 月 2 日地铁大客流、停车场内外权责交接、AI 工单流转四种情景。
- 每个事件阶段均呈现主决策主体、触发信号、权限、协同方、权责边界和处置结果。
- 将“九龙治水”展开为九类教学链条，包括两区属地、铁路、地铁、公安执法、道路交管、城市管理和资产平台。案例涉及的实际单位超过九家。
- 右侧决策实验区提供三类备选行动，选择后显示速度、协同和合法性后果。这是教学推演，不是现实应急指令。
- 左右看板可独立折叠，三维画布会随可用空间扩展。
- 区分案例材料、官方公开数据与教学推演值，界面内可以展开查看来源。

## 运行

直接双击项目根目录的 `index.html` 即可打开完整沙盘，不需要启动服务器。

需要修改代码时再运行：

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

构建命令会同时更新根目录的可直接打开版本。

## 目录

```text
station-sim-3d/
├── docs/                 方案、事实清单、建模说明和验收标准
├── public/data/          事实、情景和部门职责数据
├── src/                  React 与 Three.js 原型
├── app.html              开发入口
├── index.html            可直接双击打开的交付文件
└── package.json
```

CAD 底图的证据分级、待核位置和下一轮图纸要求见 `docs/07-CAD底图工作说明.md`。

## 数据边界

公开资料只够支撑站场规模、换乘结构、部分客流统计和法定职责。站内精确尺寸、闸机位置、实时列车客流、人员排班和摄像头点位尚未取得。因此，当前几何按公开结构做比例化示意，客流用可复现的合成数据驱动。停车设施按时间标注：2024 年官方口径为 P1—P7 地下停车场，2026 年公开信息新增 P8 地面停车场，避免把不同时点的数据拼成同一事实。具体说明见 `docs/02-事实与数据清单.md`。
