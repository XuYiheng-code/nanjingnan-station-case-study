交控万物如何
把“智能”放进城市运营

这不是一份设备清单，而是一次对“发现问题—派发任务—现场处置—结果核验—资源调整”全过程的拆解。报告同时划清交控万物、智慧停车、空地数智及政府部门的责任边界。

01 / Answer

先说结论

交控万物的智能化，不是给原有物业服务简单加装几台机器人。它以一体化城市运营为组织基础，用全域智能运营平台把人员、车辆、设备、事件和服务标准接到同一条工单链上；再用 AI 与物联网发现问题，由平台分类派单，交给人或设备执行，最后留下可核验的处置记录。公开材料显示，这套平台已在南京南站片区落地试跑，并接入了 81 台无人智能巡查和清洁设备。[1][2]

HOW / 怎么做

先整合城市服务事项和作业标准，再把感知、派单、执行、核验和调度放入同一平台；线下仍由人员、供应商和无人设备共同完成。

WHERE / 智能在哪

智能主要进入问题发现与识别、工单分类与就近派发、重复性清扫巡检、资源监测分析，以及面向旅客的寻车与服务触达。

SO WHAT / 有何作用

它把分散任务变成可见、可派、可追踪的事件，缩短信息传递链条；机器承担部分高频重复作业，人员转向精细清洁、异常判断和安全处置。

!

归因边界：南京南站的智能化由多家主体共同建设。智慧停车、“宁畅行”、网约车精准推送主要由交控停车、交控积图等主体实施；自动驾驶清扫和车路云基础设施还涉及南京铁投、空地数智等单位。它们构成南站整体智能化环境，但不能全部算作交控万物的业绩。[11][12][17]

81 台无人智能设备 巡查与清洁设备接入南站全域智能运营系统；公开材料未披露设备分类明细。[1]
2+6 驿站与服务点 2处云城驿站、6处服务点；节假日单日最高服务旅客4万人次。[1]
15→4 分钟 南站网约车司乘平均会合时间的公开口径；属于南站智慧停车协同成果。[10]
2,391 个泊位 “宁畅行”覆盖P1—P8停车场的公开口径；该成果不能直接归入交控万物。[10]

02 / Definition

先把三种“智能”分开

南站材料经常把数字平台、AI算法和无人设备放在同一句话里。为了避免概念膨胀，本报告按技术实际发挥的作用区分三层。

公开确认 访谈证据 机制解释 规划 / 试验 边界提醒
LAYER 01

平台数字化

把对象、任务和责任关系转成数据，让运营过程能够被记录、分派和复核。它是AI发挥作用的基础，但不等于AI。

  • 人、车、物、事件统一看板
  • 作业标准与周期工单
  • 在线派单、照片回传、后台核验
  • 市民扫码报事
LAYER 02

人工智能

用图像识别、算法匹配或模型分析完成过去主要依赖人判断的环节。南站现有证据主要集中在视觉识别、匹配和资源分析。

  • 识别积水、垃圾、车辆乱停等事件
  • 智能匹配责任人或设备
  • AI实景寻车与AR导航
  • 结合劳动模型分析资源配置
LAYER 03

自动化执行

设备能否自主感知环境、规划路径并执行任务，决定其自动化程度。机器人不必然都使用AI，应按具体功能判断。

  • 自动驾驶清扫车
  • 轨道巡检机器人
  • AGV代客泊车
  • 移动充电机器人

03 / Mechanism

智能化怎样嵌入日常运营

公开材料确认了平台、设备和集中调度；项目组访谈补出了工单如何流转。合起来看，交控万物改变的不是某一个岗位，而是从发现到核验的任务链。

OPERATING LOOP / 智能运营闭环

01定义事项服务边界、SOP、频次、责任人和验收口径
02发现问题传感器、AI巡查、市民扫码、员工上报
03识别分类算法判别事件类型、位置与紧急程度
04生成派单平台匹配责任主体，就近发送人或设备
05现场执行人员、供应商和无人设备协同处置
06留痕核验照片、位置、时间回传，后台复核
07分析调整统计人车物投入，调整排班、路线与资源

第2—4步是AI与物联网最明显的介入点；第5步体现人机协作；第1、6、7步更多是平台化管理。访谈称系统已录入500余项业务流程和作业标准，但这一数量尚无公开文件交叉验证。[7][8]

从“人找事”到“事找人”

事件被传感器、AI巡查或扫码入口捕捉后，平台生成工单并匹配责任人。这里的实质是缩短人工巡查、电话转达和层层协调的链条。

从“结果汇报”到“过程可见”

作业时间、位置、处置照片和复核结果进入同一记录，使承包服务和供应商履约有了可追溯依据。访谈还提到电子工牌与电子围栏，但公开材料未披露具体覆盖范围。[7]

从“机器替人”到“任务重分配”

自动清扫设备负责大面积、重复性作业，保洁人员转向边角精细清洁、设备无法处理的异常和现场检查。[9]

04 / Practices

实践清单：谁做了什么

下列卡片按实施主体和状态标注。点击筛选，可只看交控万物自身实践，或查看南站整体协同环境。

P01 南京交控万物 已落地试跑

全域智能运营平台

平台数字化

平台把人力、车辆、物料和运营事件纳入实时监测、分析和集中调度。南京铁投2025年度信息披露称，平台已在南站片区“落地试跑”；南京市国资委则确认该平台用于南站全域智能运营。受访方书面反馈将交控万物描述为管理总包方，负责统一标准、任务调度、过程跟踪和结果核验；这一角色定位属于企业自述。[1][2][6]

INPUT / 输入人员、车辆、设备、物料、事件与作业标准
PROCESS / 处理状态监测、工单流转、集中调度、数据分析
OUTPUT / 输出任务分配、过程记录、处置核验和资源调整依据
P02 南京交控万物 访谈确认

多入口发现与自动派单

AI + 工单

项目组访谈显示，事件可由设施传感器、市民扫码、员工巡查或AI巡查车发现。算法识别事件后，平台形成工单，就近发送给责任人员；完成后上传照片，由后台审核。受访者将其概括为“智能预警—自动派单—人工核验”。[7]

AI介入点图像识别、事件分类、智能匹配
人工保留点异常确认、现场处置、结果复核
证据限制识别准确率、误报率和派单时效未公开
P03 南京交控万物 访谈确认

AI巡查与综合巡查队伍

机器识别

南京铁投披露，交控万物已在南站片区组建城市综合巡查队伍。访谈进一步称，AI巡查设备可识别积水、白色垃圾、满溢垃圾桶、车辆倒伏、占道经营等问题，并触发工单；受访者称当前可识别25类事件，这一数字尚待公开材料验证。[2][7]

改变的环节高频巡查和问题上报
管理作用统一事件口径，减少只靠人工发现的遗漏
不能替代涉及执法权的处置仍由行政部门负责
P04 南京交控万物 公开确认

无人巡查与清洁设备接入平台

自动化执行

南京市国资委披露，南站基于大数据和劳动模型部署81台无人智能巡查、清洁设备，并将设备接入全域智能运营系统。公开报道没有提供81台设备的型号分布、上线率或单机效率，因此可确认的是“部署并接入”，不能据此推算总体节省了多少人力。[1]

平台作用监测设备、安排任务、汇总运行信息
设备作用承担部分重复性巡查和清扫
未公开指标可用率、替代工时、单位成本、故障率
P05 南京交控万物 公开确认

市民报事与线下服务网络

公共服务触达

南京铁投披露，交控万物上线市民报事小程序；南京市国资委披露南站已布设2处云城驿站和6处服务点，节假日单日最高服务旅客4万人次。小程序把旅客和市民纳入事件发现，驿站则保留面对面服务，两者构成线上入口与线下处置的组合。[1][2]

数字入口扫码报事、位置与问题信息提交
线下承接驿站、服务点和现场人员
尚缺证据报事量、结案率、平均响应时间和满意度
P06 交控停车 / 交控积图 已运行

智慧停车、网约车精准匹配与实景寻车

南站协同实践

“宁畅行”覆盖P1—P8停车场，提供余位查询、在线支付、AI实景寻车和网约车精确车位推送。官方材料称，系统注册用户超过100万人，网约车司乘平均会合时间由15分钟缩短至约4分钟。2025年4月，P2—P7地下网约车区域已实现智慧系统全覆盖；智慧停车一期也被列入人工智能应用创新示范场景。[10][11][14][15]

智能介入点泊位感知、数据匹配、路径提示、AI/AR寻车
直接效果减少司乘双方在停车场内反复寻找
归因说明这是南站整体智能化的重要部分，不是交控万物单独建设
P07 南京铁投 / 空地数智等 已投用或现场试验

自动驾驶清扫、轨道巡检与AGV泊车

机器人

官方报道显示，自动驾驶清扫车已在南北广场作业，依靠多传感器融合、激光雷达和摄像头完成环境感知、定位与避障，单车每小时可清扫数千平方米；P5部署轨道巡检机器人，P7展示AGV代客泊车。这些设备体现的是具体作业自动化。[9][10]

机器擅长固定范围、高频重复、规则较清楚的任务
人员转向精细清洁、安全巡视、故障和例外处置
归因说明与交控万物平台可能协同，但公开材料未证明均由其采购运营
P08 南京市 / 空地数智等 规划与测试中

6.03平方公里车路云一体化场景

不计入既有效果

南京公开提出在南站6.03平方公里范围测试自动驾驶接驳、停车、物流、无人配送和清扫等场景，并建设34个智慧路口。2026年3月，相关平台已完成南站全要素数据采集与三维建模，探索AI视觉、雷视融合和高精地图下的交通感知。由于多项内容仍处在测试或规划阶段，本报告不把它们写成已经成熟运行的交控万物实践。[16][17]

已确认数据采集、三维建模及部分测试条件
待观察常态化运营范围、监管规则、跨平台数据协同
写作规则用“规划、试点、测试”，不用“全面建成”

05 / Accountability

主体边界：不要把“南站智能化”写成一家公司的故事

南站是多主体共治空间。技术系统可以连接任务，却不会自动合并行政权、资产权和经营权。准确归因是理解这项实践的前提。

主体公开可确认的职责 / 实践与交控万物的关系不能据此推断
南京交控万物 城市综合巡查、全域智能运营平台、城市服务整合、市民报事小程序，以及人员、车辆、物料和事件的集中调度。[1][2] 由南京铁投与万物云方面共同组建，立足南站枢纽经济区落地城市空间整合服务。[3] 不能等同于南站管理委员会，也不当然拥有行政执法权。
交控停车 / 交控积图 智慧停车平台、“宁畅行”、泊位感知、网约车精准匹配、实景寻车、部分移动充电设施。[12][13] 同属南京交通相关企业体系，可与全域运营协同，但实施主体不同。 不能把停车系统的所有效果直接记到交控万物名下。
南京铁投 / 空地数智等 自动驾驶清扫、车路云平台、交通数据采集和三维建模等建设或测试。[9][17] 铁投是交控万物股东方之一，也是南站多类项目的建设、协调主体。 股权关系不等于每个项目都由交控万物实施。
政府与驻站部门 交通、城管、公安、铁路等部门分别承担监管、执法、安全和运输组织等法定职责。 交控万物可报告事件、提供运营信息和承接服务，不替代法定部门。 平台派单不等于行政命令，数据汇聚也不改变权责边界。
万物云城产品体系 企业官网展示了“全域智能运营平台”、AI巡查、IoT接入和工单闭环等通用产品能力。[4][5] 为理解南站平台的技术逻辑提供产品级参照。 其他城市案例中的算法、设备和效果，不能直接当作南站本地事实。

07 / Judgment

怎样评价这项实践

它首先是一项运营组织改造，其次才是设备升级。

交控万物最值得注意的部分，不是某一种算法，而是把分散在物业、市政、秩序维护和旅客服务中的任务，转成一套共同可读的事件与工单。

  1. 空间整合：以南站片区为服务对象，尝试跨越单一物业项目的边界。
  2. 标准整合：把服务事项、频次、责任和验收要求写入系统。
  3. 信息整合：让传感器、AI、工作人员和市民成为不同的问题发现入口。
  4. 执行整合：由平台把任务交给最近、最合适的人或设备，并记录结果。
  5. 反馈整合：用历史工单和资源数据辅助排班、路线和物料配置。

但它没有自动消除治理分割

  • 访谈时，企业平台与政府平台尚未完全打通。[7]
  • 铁路、公安等数据受权限和安全规则约束。
  • 交控万物不能代替城管、交警等部门执法。
  • 原设想覆盖更大范围，实际仍需通过采购、合同和主体协商逐步拓展。[8]
  • 节假日安全压力下仍需全员保障，说明智能化是辅助而非无人化。

08 / Limits

现有证据还不能回答什么

下面这些空白会影响对项目成效的严格评价，也是后续访谈或材料申请最值得追问的部分。

缺少算法效果指标

尚未找到南站AI识别的准确率、召回率、误报率，以及人工复核比例。因而不能判断算法在不同事件类型上的真实可靠性。

缺少前后对照

公开材料没有给出平台上线前后的平均发现时间、处置时间、结案率和重复投诉率。当前只能确认机制变化，难以估算净效果。

缺少成本口径

设备采购、维护、软件订阅、人员培训和数据治理成本未公开；“降本增效”目前主要来自受访方判断，不能作为审计结论。

跨平台协同仍有限

项目访谈称，交控万物平台在技术上可对接政府系统，但受数据授权和制度边界影响，当时尚未完全接通。[7]

物理容量不会因算法消失

停车位、道路和候车空间的容量仍是硬约束。智能匹配可改善周转与寻路，却不能在极端客流下凭空增加空间。

企业披露需交叉核验

企业官网可用于理解产品逻辑，访谈可解释运行过程，但两者都可能带有自我呈现倾向。涉及成效的结论应优先采用政府公开数据或可复核业务记录。
