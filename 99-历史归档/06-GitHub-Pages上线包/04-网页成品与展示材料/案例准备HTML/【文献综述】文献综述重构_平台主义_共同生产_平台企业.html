文献地图 A

城市数字化转型中的平台主义

01

SOURCE这条脉络经历了从“政府即平台”的技术架构想象，到“城市即平台”的创新基础设施，再到“平台城市主义”对权力、数据和中介关系的分析。研究焦点也由平台能提供什么，转向平台如何改变城市。

2011—2013政府即平台

共享数据、标准和基础设施，支持外部主体参与服务开发。

2016—2018城市即平台

平台成为组织城市创新和持续协作的架构。

2018—2022平台城市主义

关注平台化、基础设施化及其塑造的权力几何。

2022—2026类型化与本土化

讨论公共服务中介、混合能动性和中国城市的国家—平台关系。

经典观点与前沿推进

文献节点主要观点对本文的启发
O’Reilly（2011）；Janssen与Estevez（2013）政府提供可复用的规则、数据与基础设施，使服务创新分布于多元主体。平台具有制度接口和组织接口，功能不能缩减为一套信息系统。
Anttiroiko（2016）；Ansell与Gash（2018）城市平台和协作平台依靠专门资源、中介能力与持续编排维持多项协作。平台可以承接反复发生的跨部门协作，减少逐事协调。
Plantin等（2018）；van Dijck等（2018）；Barns（2020）平台逐渐基础设施化，数据提取、接口规则和生态控制随之成为治理问题。考察谁控制接口、分类、准入和数据，才能看见平台背后的权力。
Caprotti等（2022）；Caprotti与Liu（2022）平台城市主义是新的社会技术中介，可表现为公共服务中介与公私混合能动性。中国城市平台需要同时分析政府主动塑造与企业能力进入。
陈水生（2021）；孙志建（2022）；锁利铭等（2025）；吴晓林（2026）“一网统管”和平台主义城市治理说明，平台通过事件化、网络连接与政府的生态塑造重组城市运行。平台缓和组织碎片化，也可能形成新的平台边界和控制集中。

贡献

  • 把平台从技术工具提升为城市治理关系和权力结构。
  • 揭示数据、接口、标准、准入规则的组织含义。
  • 解释平台为何能够连接多部门、多企业与多类使用者。

边界

  • 宏观批判和商业平台研究较多，对平台内部的合同、人员和现场运营关注较少。
  • “城市即平台”“政府即平台”“平台企业”时常混用，组织层次并不清楚。
  • 连接关系如何转化为稳定服务生产，仍缺少过程机制。

INFERENCE这条文献提供了“平台何以兴起”的解释，却不能单独回答南京南站平台由谁创制、怎样经营。研究需要由平台的宏观关系结构进入平台中的服务生产。

文献地图 B

围绕数字化平台的共同生产

02

SOURCE共同生产研究从公共服务生产函数出发，核心标准是专业生产者之外的主体直接投入时间、信息、能力或行为，并对服务产出发生影响。数字平台扩展了连接范围，也用准入、界面和分类规则重新分配参与机会。

1981—1996生产性投入

常规生产者与消费者生产者共同投入资源。

2007—2017类型与阶段

区分参与者、共同设计、共同交付与共同评价。

2012—2020数字化扩展

众包、政府即平台、自助服务和信息分布差异。

2021—2026包容与风险

平台设计、数字能力、公共价值和价值损耗进入研究中心。

共同生产的概念门槛

概念识别标准与本文的关系
共同生产外部主体直接、积极地向公共服务生产投入资源。需要证明政府、企业或使用者的投入进入了实际服务过程。
组织间协作组织共同决策、协调或执行任务。可以支持共同生产，但一般协调本身不足以证明共同生产。
外包／PPP合同配置政府与企业之间的交付责任。一次性购买服务仍属合同生产；持续共同投入才接近共同生产。
平台以接口、规则、共享资源、匹配、路由和反馈组织多边互动。平台可以支持共同生产，门户或App本身不能作为充分证据。
共同创造多主体互动中形成价值，范围延伸到使用情境。范围较宽，需同时关注价值创造和价值损耗。
概念控制：若案例只呈现政府与万科之间的合资关系，经典“共同生产”并不能自动成立。本文可将“平台化共同生产”限定为组织间协作生产与使用者共同生产两个嵌套层次：前者关注部门、平台企业、承包商和技术企业的互补投入；后者关注乘客、商户、出租车司机的报告、配合、自助与反馈是否进入生产过程。

贡献

  • 提供判断“共同”的严格尺度：生产性投入，而非一般参与。
  • 说明数字平台可将识别、派发、处置和反馈组织为连续流程。
  • 提醒平台的界面和分类规则会决定谁能参与、哪些诉求可见。

边界

  • 经典研究以政府—公民、专业人员—使用者为中心。
  • 数字共同生产多讨论众包、311系统和在线参与。
  • 对政府部门、合资企业、承包商共同投入资源的组织间生产解释不足。

INFERENCE南京南站的材料需要证明企业从可替换的受托服务商转为持续的生产主体，也要说明使用者如何进入事件识别、现场处置或服务评价。由此才可把“政企合作”推进为“平台化共同生产”。

文献地图 C

政府创制平台企业及其相邻理论

03

SOURCE中文研究提出“政府创制平台企业”，解释政府通过控股平台公司集中数据、标准和技术能力。国际上的公共服务公司化、混合公司与边界组织研究，则分别解释设立独立法人的原因、公私共同持有的治理难题，以及异质制度逻辑如何在组织内部共存。

理论脉络核心问题能够解释什么主要风险
政府创制平台企业政府为何创制并控制数字公共服务平台公司？平台权力集中、标准整合、需求信息汇集。“公司化／平台化领地”与基层自主性收缩。
公共服务公司化为什么把服务移入独立法人？专业管理、自主用工、独立核算和跨项目经营。公司化没有稳定的成本优势，公共控制可能弱化。
制度化PPP／混合公司为什么由公私双方共同持有？资本、知识与治理权进入共同法人，形成关系性承诺。目标冲突、决策僵局、利润挤压公共利益。
混合组织／边界组织政企逻辑怎样进入同一组织？通过董事会、协议、合同和标准配置多种制度逻辑。双重问责、商业保密与公共透明的冲突。

南京南站不能直接套用既有类型

关键边界：宋锴业、徐雅倩（2025）的经验对象主要是国资控股、政府保有最终控制权的省级数字政府平台公司。现有材料显示南京南站平台为政企各持50%，因此宜称“政府创制的场景型政企合资平台企业”或“对等股权的场景型混合平台组织”。政府创制说明组织来源，对等股权说明产权结构，场景型说明平台边界。

贡献

  • 把平台的技术架构落实到产权、法人和公司治理。
  • 解释独立组织如何承载资产、合同、人员和经营风险。
  • 为分析激励兼容、多重委托和公共责任提供制度变量。

边界

  • 国内核心研究集中于政府最终控制的省级数字平台。
  • 公司化研究尚未证明企业形式天然带来效率。
  • 对等股权的表决、僵局化解和兜底责任需由案例材料确认。

INFERENCE南京南站可把研究推进到“场景型、对等股权、运营导向”的混合平台：法定权责留在原部门，反复发生的跨部门与跨企业协调进入合资企业的日常经营。该判断是否成立，取决于平台是否实际拥有合同管理、人员编组、任务配置、供应商选择和绩效监督能力。

机制 1平台创制

以独立法人提供稳定合作入口，把临时协调变为可持续组织关系。

机制 2契约聚合

将分散合同、服务标准和绩效要求纳入可统一管理的关系结构。

机制 3能力耦合

组合政府权威与资源、企业运营能力、供应商技术和使用者信息。

机制 4责任分层

区分重大决策、日常经营、行政执法、技术性能与最终政治责任。

文献之后

进一步需要追问的五个问题

何时构成共同生产？企业和使用者必须作出持续、不可替代的生产性投入，才能与采购、外包和一般参与区分。
为什么选择50/50的场景型合资平台？需要比较科层协调、政府控股平台、普通外包与对等合资在控制、激励和经营能力上的差异。
平台怎样把外部协调转成内部运营？重点追踪资产、合同、人员、标准、数据和任务如何进入同一工作过程。
对等股权如何防止僵局与责任悬空？董事会席位、重大事项、日常授权、绩效考核、异常升级和兜底责任需要逐项识别。
人工智能改变了什么？人工智能主要增强事件感知与分类；算法的采购、校验、追溯和责任仍受既有平台制度约束。
据此，本文的问题可表述为：在行政区划和法定权责基本不变的条件下，地方政府如何创制场景型政企合资平台，将分散于部门和承包企业之间的生产要素重新组织为跨部门城市运营服务；这种平台化共同生产如何形成，又怎样通过责任分层维持公共控制？

平台化共同生产的三条研究脉络

平台进入城市治理，推动数字化转型的研究重心由技术应用转向关系重组。围绕这一变化，现有研究形成了三条彼此关联的脉络：城市平台主义关注平台如何改变城市中的数据、服务与权力关系；共同生产研究讨论政府、企业和服务使用者如何向公共服务投入资源；政府创制平台企业研究则将视线推进到产权结构与组织载体。三者分别对应治理形态、生产关系与组织安排，共同构成理解平台化城市运营的文献基础。

城市平台主义由“政府即平台”和“城市即平台”的讨论发展而来。早期研究强调政府通过共享数据、标准和基础设施支持外部主体开发公共服务（O’Reilly，2011；Janssen和Estevez，2013），此后平台逐渐被视为组织城市创新与持续协作的治理架构（Anttiroiko，2016；Ansell和Gash，2018）。平台城市主义研究进一步揭示，平台在提供连接的同时也通过数据提取、接口控制与分类规则重组城市权力（Plantin等，2018；Barns，2020；Caprotti等，2022）。国内对“一网统管”和平台主义城市治理的研究说明，平台可以通过事件化管理和网络连接缓解部门分割（陈水生，2021；孙志建，2022；锁利铭等，2025；吴晓林，2026）。这条脉络解释了平台为何成为城市数字化转型的重要组织形态，但对平台内部的合同、人员、经营和现场处置关注较少。

共同生产研究提供了分析平台内多主体关系的生产视角。Parks等（1981）将共同生产界定为常规生产者与消费者生产者共同投入资源，Ostrom（1996）进一步强调不同组织边界中的行动者共同形成公共物品或服务。后续研究从参与主体、生产阶段与贡献内容细化了共同生产的类型，并把价值创造及价值损耗纳入分析（Bovaird，2007；Brandsen和Honingh，2016；Nabatchi等，2017；Osborne等，2016）。数字技术扩大了信息汇集和服务协作的范围，也会通过数字能力、界面设计和分类标准形成新的参与差异（Linders，2012；Meijer，2012；Lember等，2019；Clifton等，2020）。这类研究多以政府—公民和专业人员—使用者关系为中心，对政府部门、平台企业、承包商和技术供应商共同投入资源的组织间生产着墨有限。为避免概念泛化，平台化共同生产仍须以直接、持续的生产性投入为识别标准。

政府创制平台企业研究把平台问题落实到独立法人和组织控制。宋锴业、徐雅倩（2025）指出，政府通过控股平台企业集中数据、标准和技术能力，可以降低跨部门公共服务中的信息分散，同时也可能形成新的“公司化／平台化领地”。公共服务公司化研究表明，独立法人有利于形成专业管理、自主用工和持续经营能力，却没有稳定的成本优势（Andrews等，2022；Bernier等，2022；Bel等，2022）。制度化公私伙伴关系与混合公司研究则发现，共同法人能够将公私双方的资本、知识与治理权纳入持续协商，也会带来目标冲突、决策僵局和公共利益保护问题（Cappellaro和Longo，2011；da Cruz和Marques，2012）。混合组织和边界组织理论由此提醒研究者考察董事会、股东协议、合同、标准与问责制度如何配置公共责任和商业经营。既有“政府创制平台企业”研究主要以政府最终控制的省级数字平台为对象，对政企对等持股、围绕具体城市场景持续经营的平台组织解释不足。

三条文献之间仍有一段尚未打通的机制链：平台主义揭示多边连接和规则控制，共同生产说明多元主体的生产性投入，平台企业研究解释产权与组织选择，现有研究较少说明三者如何在具体城市运营场景中结合。南京南站案例的理论价值正在于此。本文将其界定为政府创制的场景型政企合资平台企业，考察平台创制如何提供稳定的组织入口，契约聚合如何重整分散的服务关系，能力耦合如何组合政府权威、企业运营、供应商技术与使用者信息，责任分层如何在企业经营、行政执法和最终政治责任之间划定边界。由此可以进一步解释，在行政区划和法定权责基本不变的条件下，平台如何把外部的政企协调和企业间协调转化为连续的公共服务生产过程，以及人工智能的感知与分类能力如何嵌入这一过程。

证据纪律

目前应当保留的开放问题

这些问题不宜由理论推断替代，需要在章程、合同、访谈和运营记录中逐项确认。

  • OPEN50/50股权是否对应表决权严格对等，政府方是否保有特别表决权或否决事项？
  • OPEN原有合同是转签至合资公司、委托统一管理，还是仍由公司进行联络协调？
  • OPEN人员是否进入统一劳动与指挥关系，平台能否选择、更换和考核下游供应商？
  • OPEN数据、算法、设备和服务标准由谁控制，合作退出后如何处置？
  • OPEN公共安全、行政执法、应急处置、系统性能和最终政治责任分别由谁承担？
  • OPEN平台带来的改善体现为服务结果、协调成本下降，还是两者兼有？
