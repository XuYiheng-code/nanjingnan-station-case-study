# 南雍治道创新作品资料包

创新作品名称：南站协同官：南京南站跨主体协同案例教学与模拟推演作品集

## 建议查看顺序

1. 在线展示：<https://hubcoord.cn>，无需登录。
2. 三维治理沙盘：打开 <https://hubcoord.cn/cad/>，可切换空间层次、治理图层和案例情景。
3. 离线总入口：双击 `02-南站协同官-离线演示与源码/nanjing-south-hubcoord/南站协同官-直接打开.html`。
4. 离线交互：双击 `02-南站协同官-离线演示与源码/nanjing-south-hubcoord/南站协同官-工作台Demo.html`，可体验证据检索、角色选择、协同议题生成、人工确认、越权拦截和纪要下载。
5. 离线三维沙盘：打开 `02-南站协同官-离线演示与源码/nanjing-south-hubcoord/static/cad/app.html`。部分浏览器会限制本地 JSON 读取，如遇到数据未加载，请使用在线地址或按源码 README 启动本地服务。
6. 作品导览：播放 `01-南站协同官-作品导览视频.mp4`，时长 3 分 36 秒。
7. 作品说明：打开 `创新作品说明表-南雍治道.docx`。

## 文件说明

- `01-南站协同官-作品导览视频.mp4`：作品导览短片，1920×1080，H.264/AAC。
- `02-南站协同官-离线演示与源码`：离线页面、服务端源码、结构化案例数据、权责规则、接口契约、测试集和技术说明。
- `创新作品说明表-南雍治道.docx`：按大赛附件模板填写的创新作品说明表。

## 运行说明

离线总入口和工作台 Demo 无需安装软件，使用常见桌面浏览器即可打开。若需查看服务端持久化与审计流程，请按 `02-南站协同官-离线演示与源码/nanjing-south-hubcoord/README.md` 运行本地服务；首次安装 Python 依赖需要联网。

作品使用的是团队审阅后整理的展示材料、固定权责规则和教学模拟数据。它不连接南京南站真实业务系统，不读取原始访谈、车牌、旅客轨迹或真实工单，也不会向行政部门发送处置指令。页面中的智能体结果用于案例教学和模拟推演，不替代治理成效评估或正式行政决定。
