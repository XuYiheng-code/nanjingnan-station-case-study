# 南京南站案例动画设计说明

## 模式与口径

- 创作模式：自主自由创作。
- 封面标题：《从平台化到智能化：政企共创平台企业何以化解行政分割难题？》；副标题为“——以南京南站跨区域公共交通枢纽为例”。标题已与提交版 Word 底层文本逐字核对。
- 目标：用一条可核验的故事线解释“组织如何为人工智能创造运行条件，以及制度边界为何仍然存在”。
- 受众：公共管理案例大赛评委、教师与学生。
- 画幅：1920×1080，30fps，约 3 分 37 秒。
- 语言：普通话旁白，简体中文字幕。旁白使用阿里千问 Qwen3-TTS 的 Maia 女声，以“温柔知性、克制自然、纪录片解说”为表达指令。
- 字幕：每个字幕片段最多 20 个字符，强制单行显示，并根据字数在 56–58px 间微调字号；禁止标点孤立、行首标点和词内断开。
- 数据口径：只采用案例正文、访谈整理稿和案例网站已经标明的数字与判断。真实调研照片保留来源说明，不把动画重构画面标为实拍。

## 叙事重点

必须讲清四件事：南京南站的条块分割；停车场内部与公共道路之间的协同困境；2024 年交控万物通过逐项承接形成统一运营界面；城市小脑的“感知—派单—处置—复核—记录”流程及其执法、数据、资产和属地边界。成片不出现具体停车场编号。

## 视觉方向

选定“纪实纸面 + 城市信号”方向。照片承担证据，动画承担关系解释。镜头稳定，整体能量低到中；时间轴、汇流和任务回路有清晰动作，结尾提升一次。避开赛博霓虹、群发扫光、拟真数字人和未经证实的灾难场景。

视觉 tokens：

- 墨黑 `#11100e`，深蓝 `#071926`，纸白 `#f3efe6`，信号橙 `#f28c45`，冷蓝 `#8fd7ff`。
- 标题：Songti SC / STSong；正文：PingFang SC；数据和标签：SFMono-Regular。
- 圆角 22px，细线 1px，纸面噪声轻量叠加。
- 动效性格：专业信赖，主入场 21–36 帧，不弹或仅 1.02 倍微过冲；转场 10–18 帧；信息落定至少 30 帧。

## 镜头映射

| 信息 | 运动语法 | 来源 |
|---|---|---|
| 站区全貌与关键数字 | 升降臂式拉升 + 照片推远 | `crane-rise-reveal`，按真实照片改写 |
| 多主体碎片化 | 节点网络逐一连线、边界分区 | 自定义关系图 |
| 2011—2024 治理尝试 | 横向时间旅行、末节点急停 | `timeline-travel` |
| 多甲方到统一运营界面 | 多源贝塞尔曲线汇入单点 | `bezier-source-converge-merge` |
| 城市小脑识别现场 | 扫描线先到、框和标签后到 | `scanline-annotate-focus` |
| 红线内外 | 同一实景上分割线慢扫和权限标注 | 参考 `before-after-slider-scrub` 的快甩慢扫节奏 |
| 结尾回收 | 已展示照片与机制卡四方飞入围住问题 | `outro-group-photo-launch` |

## 文案审校记录

场景为 `public-writing`，采用 `standard + structural`。先按 `humanizer-zh` 排查套话、过度拔高和无源归因，再按 `shuorenhua` 清理互联网黑话与表演性工程师腔。保护数字、年份、组织名、访谈事实和责任主体；删去无源评价与宣传性结论。结尾保留研究判断，不使用“赋能”“闭环”“颠覆”等包装词。
