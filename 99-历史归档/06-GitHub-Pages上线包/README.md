整理时间：2026-09-07

这个目录把南京南站案例相关的创新作品、终版视频、网页成品和可继续开发的源码集中到一起。原来的文件夹没有移动或删除；这里是复制出来的管理总包，方便后续提交、复盘和继续开发。小南问答助手的最新前后端、知识数据与验收脚本已整合到可运行源码目录，线上入口为 <https://qaq.hubcoord.cn/assistant.html>。

`00-总览/文件清单.txt` 是自动生成的文件清单，可以用来快速查找具体文件。

## GitHub Pages

已补齐：

- `index.html`：作品合集首页
- `site-assets/portfolio.css`：首页样式
- `web-media/`：网页预览视频
- `.nojekyll`：让 GitHub Pages 原样发布静态文件
- `.gitignore`：排除依赖、缓存和原始大视频

具体上线步骤和后续开发放置规则见 `00-总览/后续开发与GitHub上线说明.md`。需要注意的是，原始高清视频中有多支超过 100MB，不适合直接作为普通 Git 文件上传；线上展示先使用 `web-media/` 下的预览版。

两种上传方式：

- 用 Git 命令推送当前总包：`.gitignore` 会排除原始大视频和上线包副本。
- 用浏览器或 GitHub Desktop 直接上传：优先上传 `06-GitHub-Pages上线包/`。
