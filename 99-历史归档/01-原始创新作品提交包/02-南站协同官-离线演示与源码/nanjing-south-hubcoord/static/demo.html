CHOOSE A DEMONSTRATION PATH

两条路径，分别证明“能协同”和“不会越权”

无需配置。选择一条路径，页面会使用同一份模拟情景、证据卡和权责规则运行。

PATH A / 约 3 分钟

完成一次正常协同

五个专门任务依次处理事件，两名规定角色分别确认后，议题卡才进入完成状态。

PATH B / 约 30 秒

测试一次越权请求

尝试“直接行政处置”，查看权责核验和安全审计如何禁止确认并要求升级。

WHAT THE DEMO SHOWS

评委点下按钮后，会看到四件事

  1. 01
    输入

    一条模拟的枢纽现场事件，带时间、空间和来源状态。

  2. 02
    智能体处理

    五个任务节点依次做事件归并、证据检索、权责核验、议题起草和安全审计。

  3. 03
    人工确认

    跨主体事项不会自动完成，需现场主管和综管办值守人员分别说明理由。

  4. 04
    输出

    系统给出一张协同议题卡，记录证据编号、规则编号、确认进度和最终状态。
