### 1.2 作品规格与硬性约束

- **选题报告（第一阶段）**：1500–3000 字。建议含：选题名称、选题背景、研究意义、案例摘要、研究问题、研究思路、研究计划。
- **案例分析报告（第二阶段）**：全文 **≤15000 字**，含 **"案例正文" + "案例分析" 两部分**。
- **创新作品（第二阶段可选）**：参评「案例创新奖」，须附 **约2000字文字说明**（所用技术工具、创作过程、嵌入/交互方式、对案例呈现与教学研讨的赋能）。
- **查重**：全文重复率 **<10%**（CNKI 学术不端系统，去引用）。
- **AIGC 红线**：AI 生成内容须 **红色字体标注**，且 **<10%**；**主体观点、核心论点、关键数据论证、创新性分析与研究结论不得为 AIGC**。语言润色、语法检查、数据整理、图表美化**不算** AIGC。

### 1.3 主题方向与定位

- 紧扣 **"智能社会治理"**，突出智能社会治理领域的**应用实践、制度创新与独特价值**，**"以人维度小切口为优"**。
- 可选方向：政府管理、**公共服务**（教育/医疗/民生/养老等）、应急管理、**社会治理**、**城乡治理**、纪检监察、可持续发展、伦理与安全、网络空间治理、数字沉浸治理、国家智能社会治理实验基地实践案例等。
- **我们的落点**：南京南站案例最贴 **公共服务 / 城乡治理 / 社会治理** 三方向交叉。**小切口** = 一个跨区域交通枢纽里，"政府创制平台企业 + 智能运营平台"如何破解碎片化治理。完全契合"小切口、应用实践、制度创新"。

### 1.4 奖项与激励（决定投入强度）

- 常规奖：一等奖 1（5000元）、二等奖 3（3000元）、三等奖 5（1000元）、优秀奖若干。
- **案例创新奖**：5000元/队 —— **这就是"智能体"线的专属赛道**。
- **收录激励**：优秀案例入 **中国公共管理案例库（chinacases.cn）**，并有机会入选 **《智能社会治理教程》教辅材料并出版**。→ 对升学/简历/学术履历价值极高，是比奖金更值得争取的目标。

> **战略判断**：两条线不是"主+副"，而是**互为杠杆**。案例文本冲常规奖 + 案例库收录；案例智能体冲案例创新奖，并在**决赛现场答辩**时成为最强差异化武器（评委亲手与"南京南站"对话）。智能体做得好，能把一份"还不错的报告"抬进决赛圈。

## 二、案例文本：在现有基础上怎么做得更好

### 2.1 现状盘点（我们已有的"家底"很厚）

已成型的核心资产：
- **理论框架**：「技术—组织—制度」三层递进框架，贯穿 **效率逻辑 vs 合法性逻辑** 双主线（见 `过程文本/三、分析框架与理论命题`）。
- **核心概念**：**政府创制平台企业**（交控万物）—— 嵌入科层、兼具平台特性与公共属性的"准治理主体"；**有限的整体性治理**。
- **三组理论命题 + 推论**（命题1技术降本 / 命题2混合组织承接 / 命题3制度三重刚性：法律授权、数据主权、属地责任）。
- **概念界定**：数字治理→智能治理→智慧治理→整体性智治的范式演进（已对接陈振明"人工智能+"、张成岗、杜玉春/张小劲等2025–2026前沿文献）。
- **一手实证**：南京南站调研录音转录、交通集团访谈、万物云/灵石AIoT资料；具体抓手包括 **"城市小脑+云城队长"全域智能运营平台、25类场景算法、500余项业务流程标准、数字工单闭环**。
- **文献库**：交易成本经济学经典与发展、平台企业供给公共服务、数字治理生态、技术与组织互构等数百篇，已分类。

**结论：文本不是从零开始，而是"高位精修"。** 框架与命题已达到准发表水平，问题在于**对齐赛事口径**和**补足团队自评已发现的短板**。

### 2.2 关键差距诊断（来自团队自身的 AI 审稿 + 赛事要求）

团队在 `五、案例分析` 已自查出 5 个问题，结合赛事口径，归并为 **5 个必须攻克的缺口**：

1. **"智能"含量需前置、加浓**：现框架以交易成本(TCE)为底层引擎，但赛事评的是 **"智能社会治理"**。需把 **AI/智能技术（城市小脑、25类算法、AIoT感知、数据闭环）从"工具"提升为"叙事主角"**，让评委一眼看到"智能"，再用 TCE 解释"为何有效"。**TCE 是里子，智能治理是面子，面子要足。**
2. **动态过程揭示不足**：现文偏"静态三层结构"。需补 **交控万物"试探—整合—扩张"的时间线演化**（从基础物业切入→逐步整合→边界扩张），把"过程追踪"做实。
3. **边界处的能动应对刻画不足**：现文答好了"边界在哪"（执法权/数据/属地），但缺"创新主体如何与天花板协商共处"——需精描三组实践智慧：**"巡查—劝导—上报"应对执法权禁区、关系性契约获取数据、商业谈判实现有限统合**。
4. **与既有研究的显性对话不足**：需把本案 **与"一网统管"、平台化整体性政府、城市大脑** 等明确对比，凸显"政府创制平台企业"作为**第三条道路**（区别于纵向赋权、高位驱动、分散发包）的独特贡献。
5. **字数纪律**：报告 **硬上限 1.5万字**（含案例正文+分析）。现有过程文本各章相加已远超，需做**"案例正文精炼 + 分析聚焦"的减法**，把学理铺陈移到注释/附录。

### 2.3 推进路线（两阶段对应赛程）

**阶段A：选题报告（即日 → 7/10）— 最高优先级**

把厚重框架"降维"成一份 1500–3000 字、评委 5 分钟能读懂的"钩子"：
- **标题**：建议双标题。主标题要"智能"显性化，副标题点小切口。
  候选：*《城市小脑如何"接住"碎片化枢纽：南京南站政府创制平台企业的智能整体性治理实践》*（仅供打磨）。
- **必含七要素**：选题名称 / 背景（人工智能+ 国家战略 + 枢纽碎片化痛点）/ 意义 / 案例摘要 / 研究问题（何以可能·何以可行·何以受限）/ 研究思路（技术—组织—制度 + 双逻辑）/ 研究计划（含"案例智能体"创新作品规划，提前埋点）。
- **打法**：用"问题—张力—独特发现"三段抓住评委。突出 **"小切口 + 已完成一手调研 + 已有创新作品原型"** 三个加分项（人无我有）。

**阶段B：案例分析报告（入围后 7/22 → 9/7）**

- **案例正文（约6–7千字）**：以**故事化 + 过程追踪**写南京南站困境与交控万物的演化，补足缺口2、3的动态细节。
- **案例分析（约7–8千字）**：三层框架 + 三命题 + 显性文献对话（缺口1、4），收尾落到"有限的整体性"。
- **合规作业**：核心分析全程人写；AI 仅用于润色/查证/图表，并红色标注（缺口对应 1.2 AIGC 红线）；CNKI 自查重复率<10%。

## 三、案例智能体：把"南京南站"做成一个很能打的智能体

### 3.1 战略定位：精准对接「案例创新奖」

赛事「创新作品」明列的形式中，**"案例智能体：基于AI大模型开发的对话式案例助手，可实现案例模拟与超拟真对话"** —— 这就是为我们量身定做的赛道。目标不是"做个聊天机器人"，而是做一个 **让评委/学生能亲手"走进南京南站、扮演治理主体、做决策、看后果"的案例教学与决策推演智能体**。

**很能打 = ①紧扣案例理论内核（不是通用问答）②扎根一手调研语料（不编造）③可交互推演（不是只读）④决赛现场可演示（视觉冲击）。**

### 3.2 可复用的现有资产（不重复造轮子）

| 现有资产 | 复用点 |
|---|---|
| `aifit_demo`（gateway/orchestrator/agents/knowledge/console 全栈多智能体系统） | **直接复用编排与知识检索骨架**，把领域从"安防/AIfit"换成"南京南站案例" |
| `interview-robot`（Next.js + ASR + chat + session） | 复用**对话前端 + 语音交互**，让评委可"语音问南京南站" |
| MPA选题与研究系统 + `knowledge` MCP（语料库语义检索/知识图谱） | 把**调研录音转录、访谈、政策、文献**灌入，做成**可溯源 RAG**底座 |
| 一手语料：南站调研录音、交通集团访谈、万物云/灵石资料、政策文件 | 智能体的"真实性"护城河 —— 别队拿不到这批一手料 |

### 3.3 智能体设计：三个"很能打"的功能内核

**内核1 ｜ 可溯源案例问答（RAG，反幻觉）**
- 用户问"交控万物怎么处理违停？"→ 智能体基于**真实调研语料**作答，并**给出出处**（哪段访谈/哪份文件）。
- 价值：体现"原创调研"，杜绝 AIGC 编造，直接呼应赛事合规要求。

**内核2 ｜ 多主体角色推演（呼应"多甲方对一乙方"理论核心）★差异化王牌**
- 用户选择身份：**政府（多部门甲方）/ 交控万物（乙方平台）/ 市民**，与其他由 AI 扮演的主体对话博弈。
- 设三个**经典治理两难场景**让用户做决策：
  1. 执法权禁区（违停只能"巡查—劝导—上报"，不能罚）
  2. 数据壁垒（靠关系性契约拿部分数据）
  3. 属地考核分割（靠商业谈判做有限统合）
- 选不同策略 → 智能体推演**交易成本变化 + 合法性约束 + 后果**，最后点出"有限的整体性"。
- 价值：**把抽象理论变成可玩的决策实验**，这正是"案例模拟与超拟真对话"的极致形态，也是决赛答辩的爆点。

**内核3 ｜ 治理数据看板（可顺带参评"数据看板"形式）**
- 可视化呈现：站区工单闭环、25类场景算法分布、响应时效、三重制度刚性边界图。
- 价值：与文本的框架图联动，强化"智能"观感。

### 3.4 技术路线（务实、可在赛程内交付）

- **底座**：直接 fork `aifit_demo` 的 orchestrator + knowledge 模块；前端取 `interview-robot` 的 chat/ASR。
- **模型**：用最新最强模型（如 Claude Opus 4.x）做角色扮演与推演；RAG 检索保证溯源。
- **语料工程**：把一手调研材料清洗 → 切片 → 入知识库（`knowledge` MCP 已具雏形）。
- **合规**：智能体属"创新作品"，与正文 AIGC 红线分开计；但**正文里引用智能体产出的分析仍须人工复核与标注**。
- **交付物**：①可访问的 Web Demo ②决赛现场离线可演示版 ③约2000字技术说明（工具/过程/交互/赋能）。
