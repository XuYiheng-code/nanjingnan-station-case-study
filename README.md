# 南雍治道 · 南京南站案例作品合集

**2026 中国智能社会治理公共政策案例分析大赛参赛作品**

从平台化到智能化：政企共创平台企业何以化解行政分割难题？——以南京南站跨区域公共交通枢纽为例。

![南雍治道作品主站封面](docs/screenshots/cover.jpg)

主站封面以南京南站航拍为底，叠加 Canvas 信号粒子动画，配「碎片化 → 平台化 → 智能化」三阶段演进与六入口索引。

---

## 作品速览

### 01 · 主站封面

![主站封面](docs/screenshots/cover.jpg)

封面页：南京南站航拍底图 + 信号粒子动画 + 三阶段演进 + 六入口索引。

### 02 · 案例故事

![案例故事](docs/screenshots/story.jpg)

以 SC-01 现场为主线，呈现「一座车站，几套治理系统」的真实张力：大客流、多方式、三区两治、跨省道路权与协同复盘。

### 03 · 案例分析

![案例分析](docs/screenshots/analysis.jpg)

八节拆解：传统方式为何失灵 → 平台如何改变结构 → 效能边界在哪里 → 政企共创启示。

### 04 · 影像作品

![影像作品](docs/screenshots/film.jpg)

7 分 43 秒正式参赛案例片，1080P，内嵌 HTML5 播放器与字幕。

### 05 · 空间沙盘（CAD）

![空间沙盘](docs/screenshots/cad.jpg)

三维车站沙盘，CAD 底图叠加案件场景与决策时间线，可在浏览器内交互切换治理结构与决策主体。

### 06 · 协同实验（案例智能体）

![协同实验](docs/screenshots/demo.jpg)

南站协同官案例智能体可操作 Demo：60 秒工作流 + 三分钟实录 + 议题卡样张。

### 07 · 问答助手 · 小南

![问答助手](docs/screenshots/assistant.jpg)

基于已审阅案例材料的 RAG 问答助手，支持事实核对、机制分析、相关方模拟与中文语音输入。
