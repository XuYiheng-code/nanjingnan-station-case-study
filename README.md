## 本地打开

打开根目录 `index.html` 即进入作品主站封面。若需单独查看某一板块：

- 案例正文：`01-线上一致网页/story.html`
- 案例分析：`01-线上一致网页/analysis.html`
- 参赛案例片：`01-线上一致网页/film.html`
- 空间沙盘：`01-线上一致网页/cad/app.html`
